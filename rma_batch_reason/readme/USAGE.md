To use this module:

1. Go to RMA > RMA Batches
2. Create or open an RMA Batch
3. In the form, locate the "Reason" field (added after the Operation field)
4. Select a reason from the dropdown
5. The reason will automatically be applied to new RMAs created within this batch
6. Existing RMAs without a reason will be updated when the batch reason is set
7. Individual RMAs can override the batch reason by setting their own reason
